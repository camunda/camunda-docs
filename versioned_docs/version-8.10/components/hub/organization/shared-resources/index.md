Shared resources are the element templates that users publish to your organization. Everyone in the organization can use them in their diagrams.

## Open shared resources

At the organization level in Camunda Hub, click **Shared resources** in the left navigation. The page gives you an overview of all shared resources within your organization.

## What you can do

Organization users without special organization permissions can:

- View all the resources published within the organization.
- Open the versions list of a resource if they are a [Workspace Admin or Editor](/components/hub/organization/manage-workspaces/manage-workspace-members.md#workspace-roles) of the workspace of the resource.

[Users with elevated access](/components/hub/workspace/modeler/collaboration/collaboration.md#elevated-access) can also:

- View additional details about the published version.
- Open the versions list of a resource if they are an [Organization Admin or Organization Owner](/components/hub/organization/users-and-roles.md#elevated-workspace-access).
- Unpublish an element template directly from this view.

## Publish to shared resources

You publish an element template from the editor, or you promote a template version from its versions list. See [manage published element templates](/components/hub/workspace/modeler/element-templates/manage-element-templates.md#manage-published-element-templates) and [create an element template](/components/hub/workspace/modeler/element-templates/save-as-element-templates.md).

## Shared resources and the catalog

Shared resources are separate from the [catalog](/components/hub/organization/manage-catalog/index.md). Teams use both sources when they model. When you [browse all resources](/components/hub/workspace/modeler/modeling/browse-all-resources.md) while modeling, the **Catalog assets** and **Shared assets** badges show where a resource comes from.
