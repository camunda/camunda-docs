# Advanced runnable examples

:::caution Technical Preview
The PHP SDK is a **technical preview**. Its API surface may still evolve and changes may not follow semantic versioning. Pin an exact version if you need stability.
:::

The [`examples/advanced/`](https://github.com/camunda/orchestration-cluster-api-php/tree/main/examples/advanced/) directory contains self-verifying
local-cluster scenarios for a test drive, resilient worker behavior, idempotent
message correlation, and PHP process-forking.
