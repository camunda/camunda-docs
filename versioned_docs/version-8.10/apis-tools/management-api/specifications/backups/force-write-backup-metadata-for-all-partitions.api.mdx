<MethodEndpoint

  path={"/backupRuntime/state/sync"}
  context={"endpoint"}
></MethodEndpoint>

Triggers a sync of backup metadata (checkpoint entries and backup ranges) from
the internal state to the backup store for every partition, independent of any
backup being taken or confirmed.

Syncs every physical tenant unless `physicalTenant` narrows it to one. As for
`POST /backupRuntime`, the query parameter is only read when the request carries a
`Content-Type: application/json` header.
