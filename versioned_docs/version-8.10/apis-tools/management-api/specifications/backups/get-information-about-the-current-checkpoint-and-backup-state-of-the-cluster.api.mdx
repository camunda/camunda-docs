    "Get information about the current checkpoint and backup state of the cluster"

<MethodEndpoint
  method={"get"}
  path={"/backupRuntime/state"}
  context={"endpoint"}
></MethodEndpoint>

A detailed information of the backup with the give backup id. Covers every physical tenant
unless `physicalTenant` narrows it to one. Every partition entry names the physical tenant
it belongs to, as partition ids restart at 1 in each tenant.

</Heading>

      description:

        title: "Physical Tenant ID",
