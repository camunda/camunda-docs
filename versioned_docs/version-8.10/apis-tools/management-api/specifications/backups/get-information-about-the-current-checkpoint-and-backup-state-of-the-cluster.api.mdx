<MethodEndpoint
  method={"get"}
  path={"/backupRuntime/state"}
  context={"endpoint"}
></MethodEndpoint>

Returns, for every partition, the latest checkpoint, the latest backup, and the backup
ranges. Covers every physical tenant unless `physicalTenant` narrows it to one. Every partition entry names the physical tenant it belongs to, as
partition ids restart at 1 in each tenant.
