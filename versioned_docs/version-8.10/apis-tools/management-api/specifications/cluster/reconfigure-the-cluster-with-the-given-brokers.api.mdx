  path={"/brokers"}
  context={"endpoint"}

The final cluster consists of only the brokers in the request body. New brokers in the request will be added to the cluster. Any existing brokers that are not part of the request will be removed from the cluster. The partitions will be re-distributed to the given brokers. All brokers must be running to complete the operation unless the parameter force is set to true.
