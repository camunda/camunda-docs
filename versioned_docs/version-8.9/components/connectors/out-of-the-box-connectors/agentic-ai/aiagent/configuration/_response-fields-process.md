As the agent context is only needed outside the ad-hoc sub-process when modeling a response follow-up or external processing, there is an additional field to configure whether the context should be returned as part of the response:

| Field                 | Required | Description                                                                                                                                                                                                                                                                                                           |
| :-------------------- | :------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Include agent context | No       | <p>Returns the agent context variable as part of the response object.</p><p>Necessary when modeling a response follow-up in combination with an AI agent process as otherwise the context will only be kept in the process' internal state.</p><p>Only applicable to the **AI Agent Sub-process** implementation.</p> |
