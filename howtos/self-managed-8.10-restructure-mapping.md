# Self-Managed 8.9 to 8.10 page mapping (organized by the 8.9 sidebar)

This table maps every Self-Managed page from the 8.9 docs to its 8.10 location, in either direction. 8.10 restructured the Self-Managed section (epic [#9119](https://github.com/camunda/camunda-docs/issues/9119), Phase 1 [#9345](https://github.com/camunda/camunda-docs/issues/9345)), so most `self-managed/` paths in `docs/` no longer match `versioned_docs/version-8.9/self-managed/...`.

**Legend**:

- _unchanged_ = same location in both;
- _renamed_ / _Hub consolidation_ = non-obvious move;
- _REMOVED_ = retired or consolidated (see the note for where it went).

Verified against `9345-sm-restructure-phase-1` on 2026-07-29: every non-removed 8.10 path exists, every moved path has an `.htaccess` redirect. This is a living document: update the 8.10 column whenever a Self-Managed page moves, so the `backport` skill and anyone else can rely on it. Keep using this table for as long as 8.9 (or older) remains a maintained backport target (`versions.json`).
