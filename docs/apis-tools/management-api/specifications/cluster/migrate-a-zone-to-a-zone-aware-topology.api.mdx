  path={"/zones"}
  context={"endpoint"}

Migrate one zone of a bare or partially zoned cluster to a zone-aware topology. The request contains only the zone name. Before migrating a zone, update the persisted partition distribution with `PUT /cluster/partitioning` with a zone aware partition distribution. For dual-region clusters, migrate the secondary zone first (odd-numbered nodes) and then the primary zone.
