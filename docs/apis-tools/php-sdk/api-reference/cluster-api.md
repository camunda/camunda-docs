# Cluster API

`ClusterApi` — 7 operations. Call any of these directly on the client, or via `$client->api(\Camunda\Orchestration\Api\Api\ClusterApi::class)`.

- `cancelClusterRebalance()`
- `getClusterRebalance()`
- `getClusterStatus()`
- `getClusterTopology()`
- `getStatus()`
- `getTopology()`
- `triggerClusterRebalance()`
