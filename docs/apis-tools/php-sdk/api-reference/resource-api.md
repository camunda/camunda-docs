# Resource Api

`ResourceApi` — 6 operations. Call any of these directly on the client, or via `$client->api(\Camunda\Orchestration\Api\Api\ResourceApi::class)`.

- `createDeployment()`
- `deleteResource()`
- `getResource()`
- `getResourceContent()`
- `getResourceContentBinary()`
- `searchResources()`
