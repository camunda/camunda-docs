# Domain type system

Each identifier is a distinct, self-validating value object in the `Camunda\Orchestration\Semantic` namespace. Concrete identifier types implement `Stringable` and `JsonSerializable` and expose `::of()`, `->value()`, and `->equals()`. `ResourceKey` and `ScopeKey` are factories that lift a raw string into the matching concrete type via `::of()`.
