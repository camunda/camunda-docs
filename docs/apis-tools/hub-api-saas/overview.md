## Migrating from API v1

API v1 is deprecated in Camunda 8.10 and will be removed in 8.12. It is available as part of Camunda Hub via the [Hub API v1 Swagger UI](https://hub.camunda.io/swagger-ui/index.html?urls.primaryName=api-v1). [Migrate](/apis-tools/hub-api-saas/overview.md) to Camunda Hub REST API v2 before upgrading to 8.12.
