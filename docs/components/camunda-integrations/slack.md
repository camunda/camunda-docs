Camunda for Slack is part of [Camunda app integrations](./app-integrations/app-integrations.md), which connect Camunda to the chat tool your team uses. You can run it without Microsoft Teams.

:::important
App integrations are released as an [early access](/components/early-access/overview.md) alpha feature to allow you to test and participate in development by sharing feedback before general availability, and are subject to alpha feature limitations.
:::

Find the documentation you're looking for:

- [Camunda for Slack](./app-integrations/slack.md), the `/camunda` slash command and direct message.
- [Notification rules](./app-integrations/notification-rules.md).
- [Install](./app-integrations/installation.md).
- [Troubleshoot](./app-integrations/troubleshoot.md).

This page is not the [Slack connector](/components/connectors/out-of-the-box-connectors/slack.md), which is a separate product that uses your own app registration and credentials in the process model. If your organization uses app integrations, the [App Integrations connector](/components/connectors/out-of-the-box-connectors/app-integrations.md) sends through the app your users already have connected.
