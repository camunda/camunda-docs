title: Start a new process instance
description: "After you have deployed your process to Camunda 8, you can start a new instance of this process via the play icon."
---

Start a new instance of a process from Desktop Modeler after you deploy it to Camunda 8.

1. Select a connection by following [Connect to Camunda 8](./connect-to-camunda-8.md).

   ![Connection selector showing the Dev connection selected](img/connection-selector-dev-connection.png)

2. Click the play icon to start a new process instance.

   ![start instance icon](./img/start-instance-icon.png)

3. (Optional) Enter variables for the process instance. Click **Start BPMN process instance** to deploy and start the instance.

   ![start instance overlay](./img/start-instance.png)

   Desktop Modeler shows a confirmation message when the instance starts.

   ![start instance successful](./img/start-instance-successful.png)
