---

Upload a BPMN diagram, DMN diagram, or any other supported file to a modeling project in Camunda Hub:

1. Open a workspace.
2. Open a project.
3. Choose one of the following import methods:
   - Click **Create new > Upload files**, and select the files from your computer.
   - Drag one file from your computer and drop it onto the files table.

:::tip
Alternatively, you can replace the content of an existing file with the content in your uploaded file:

    - Open an existing file. In the top navigation next to the filename, open the vertical ellipsis menu, and choose **Replace via upload**. Then, select a file from your computer.
    - Open an existing file. Then, drag one file from your computer and drop it onto the canvas.

:::

### Undo/redo management limitations

You cannot undo or redo any actions taken before an upload as the undo/redo history is cleared when a diagram is uploaded. This prevents inconsistencies between the uploaded diagram and any actions taken before the upload.
